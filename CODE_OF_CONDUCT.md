# Code of Conduct

Keyvane is built for and with independent developers from everywhere. We want this community to be welcoming, respectful and useful.

## Our standards

Do:

- Be kind and assume good intent; many contributors write in their second or third language.
- Give specific, constructive feedback on code and ideas, not people.
- Accept that people have different experience levels and help them learn.

Do not:

- Harass, insult or demean anyone, publicly or privately.
- Use sexualized language or imagery, or make unwelcome advances.
- Publish anyone's private information without permission.
- Engage in trolling or deliberately disruptive behavior.

## Scope

This applies in all project spaces (issues, pull requests, discussions) and when representing the project elsewhere.

## Enforcement

Report unacceptable behavior privately to the maintainers through the contact listed on the maintainer's GitHub profile. Reports are handled confidentially. Maintainers may remove, edit or reject contributions and may temporarily or permanently ban contributors who violate this code.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
